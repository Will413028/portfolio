# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/Will413028/portfolio/security/advisories/new)
instead of opening a public issue.

You can expect an acknowledgement within 7 days. Fix timelines follow the severity of the issue:

| Severity | Fix deadline |
|---|---|
| Critical | 7 days |
| High | 30 days |
| Medium / Low | 90 days |
